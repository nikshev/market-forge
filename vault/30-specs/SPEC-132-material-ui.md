## Summary

The overview and the chart page get a Material UI interface: one pure theme built from the scheme and
Telegram's theme parameters, an app bar with the logo, market cards with spot/perp chips, Material controls
with the channel-mode chip, alerts for load states and a chart that follows the palette. Every role and accessible
name the existing tests use stays, and the result is looked at in eight screenshots, not only tested.
