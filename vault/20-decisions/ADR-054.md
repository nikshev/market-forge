## Context

[[ADR-024]] gave six of PRD §41's eleven anti-bias rules a home and named why
the other five had none. Rule 11 — "store all discarded experiment variants to
reduce silent cherry-picking" — got one line: "experiment tracking, which
nothing here does."

Something here does now. But a registry alone does not enforce rule 11, and it
is worth being exact about why. Storing is not a checkable property: nobody can
know what someone considered and never wrote down. A registry that is merely
available is an honour system with a database attached.

The same problem afflicts PRD §0 item 13. A record with four fields satisfies
nothing if the fields can be blank, if the commit can come from a dirty tree,
and if the result is published regardless.

## Decision

**Both rules are enforced at the same place: the gate between a run and a
reportable result.**

`publish` refuses unless the run is reproducible, and names which of §0 item
13's components is missing rather than failing generically.

For rule 11 it asks for something stronger than storage: reporting a winner
means naming the field it was chosen from, and every variant in that field must
already be in the registry. Cherry-picking then requires *lying about the field*
rather than merely staying quiet about a variant.

**Recording is unconditional.** An unreproducible run is recorded, and recorded
as unreproducible with the reason in its row. Refusing to record it would leave
no trace of it at all, which is precisely the outcome rule 11 is against.

**The registry lives on the canonical plane**, not in PostgreSQL. PRD §29.B
lists `backtest_runs` and `experiment_membership` among the Iceberg tables and
ends by requiring dataset lineage of every research-grade table; [[ADR-002]]
made object storage canonical. A registry that could be edited after the fact
would defeat the rule it exists to enforce, and a lakehouse table cannot be.
PRD §30's `experiments` row remains a control-plane question, unanswered here.

## Consequences

- **Rule 11 is enforceable and not yet enforced.** The mechanism exists; none of
  the seventeen research modules reports through it. `REQ-BIAS-011` therefore
  moves to `specified` and no further — marking it `implemented` on the strength
  of an unused gate would claim the coverage [[ADR-024]] refused to claim for
  rule 2 on the strength of one engine's guard.
- **The honest limit is stated in the code.** The gate cannot stop someone who
  never mentions a variant. It stops the variant that was run, lost and quietly
  dropped, which is the case rule 11 is about.
- **A dirty working tree makes a result unreportable.** That will be
  inconvenient, and it is the point: `git rev-parse HEAD` answers in a dirty
  tree and names a tree that never ran.
- **The commit is supplied, not read.** A library that shells out to `git`
  cannot be tested and answers about whatever directory it is in. A test asserts
  the package never reaches for git or for a clock.
- **Reversible.** Nothing about the registry's shape prevents a PostgreSQL
  mirror later, and §30 may still want one for the control plane.
